# Can_Based_Control
CAN-bus based motion &amp; feeder control firmware. Teensy 4.1 (Marlin or grblHAL) as CAN master, STM32F103 Blue Pill slaves driving steppers and feeders over 500kbps CAN. Three variants: grblHAL feeder control, Marlin feeder control, and integrated Marlin motor + feeder control.
